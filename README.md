## Deployment

Proyek ini telah berhasil dideploy dan dijalankan pada platform Hugging Face Spaces.
Deployment digunakan untuk menyediakan akses publik terhadap model prediksi emisi karbon
tanpa perlu menjalankan aplikasi secara lokal.

Platform Deployment  
Hugging Face Spaces

Status Deployment  
Active

Akses Aplikasi  
https://huggingface.co/spaces/delia-ayu-nandhita/EmisiCarbonModel/tree/main
