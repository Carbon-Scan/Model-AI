## Deployment

Aplikasi ini telah dideploy pada platform Hugging Face Spaces dan dapat diakses melalui tautan berikut:

https://huggingface.co/spaces/delia-ayu-nandhita/EmisiCarbonModel/tree/main

---

## Teknologi yang Digunakan

- Python sebagai bahasa pemrograman utama  
- Machine Learning untuk prediksi emisi karbon  
- Database untuk penyimpanan dan pengelolaan data  
- Environment Variables untuk pengaturan konfigurasi aplikasi  

---

## File Utama

- `app/models.py`  
  Implementasi model AI dan proses prediksi emisi karbon.

- `app/database.py`  
  Menangani koneksi serta operasi database.

- `app/requirements.txt`  
  Daftar library Python yang dibutuhkan untuk menjalankan aplikasi.
